A comprehensive, production-ready collection of **43+ pixel-perfect, highly responsive website sections** built with **React 19**, **Tailwind CSS v4**, **Motion**, **Three.js (WebGL)**, and **Lucide Icons**.

## 📱 Mobile Responsiveness & Studio Controls

- **Interactive Studio Viewport**: Instant switching between **Desktop (100%)**, **Tablet (768px)**, and **Mobile (375px)**.
- **View All vs. Single**: Inspect individual sections or view all designs in an endless curated gallery.
- **Off-Canvas Side Drawers**: Every header and hero includes animated slide-in mobile navigation drawers with backdrop blur.

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build

# Deploy to GitHub Pages
npm run deploy
```

## 📦 Tech Stack
- **Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS v4 + Vanilla CSS
- **Motion:** Motion (formerly Framer Motion)
- **3D & Visuals:** Three.js, Canvas-Confetti
- **Icons:** Lucide React
